# 把应用源码放在这个目录

打包 fpk 前，请把从预览窗口下载的源码压缩包解压到这个 `src/` 目录里，
解压后应当能直接看到 `package.json`，也就是：

```
app/docker/src/
├── package.json      <- 必须有
├── Dockerfile        <- 已提供，保留不要删
├── .dockerignore     <- 已提供，保留不要删
├── server/ ...
└── client/ ...
```

注意：

1. 不要删除本目录里的 `Dockerfile` 和 `.dockerignore`，`docker-compose.yaml`
   里用的是 `context: ./src` + `dockerfile: Dockerfile`。
2. 不要把这个目录里的源码再套一层文件夹（例如 `src/compass/package.json`
   这样是错的），`package.json` 必须与 `Dockerfile` 同级。
3. 如果源码里已经自带 `Dockerfile`，请用本目录这一份覆盖它，
   因为本目录这份已经写死了端口 3002 和数据目录 `/app/data`。
